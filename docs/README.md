  tools, sidecar, keys, installation, and build problems).
- **[Release, Signing & Auto-Update](RELEASE.md)** — ship it: build installers per OS,
  Windows/macOS code signing + notarization, the Tauri auto-updater, and the CI

## In-app help

- The **first-run setup wizard** (shown on first launch; skippable) ends with links to
  these guides.
- **Settings -> Help & docs** lists the guides; **Settings -> Logs** opens your log
  folder for diagnostics. Open Settings any time with **Ctrl/Cmd + ,**.
